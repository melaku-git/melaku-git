### 📱 Smart Attendance System (Mobile)

A Flutter-based Android app that allows university lecturers to track student attendance in real-time using biometrics and offline-first SQLite storage. It eliminates manual roll-calls and prevents fraud.

| | |
|---|---|
| **Architecture** | Flutter · Dart · SQLite · Biometric Authentication |
| **Key Impact** | Reduces roll-call time by 80% · Works offline · Prevents attendance fraud |
